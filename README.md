# Spectra

Spectra is a personalized surf session tracker focused on fast logging and automatic condition capture.

## Repo Structure
- `spectra-backend/`: FastAPI backend (Poetry-managed)
- `Spectra/`: SwiftUI iOS app source layout

## Phase 1 Scope
- Auth, session logging, auto-condition capture, session history, basic stats
- Hardcoded SoCal spot database
- No predictions or social features yet
